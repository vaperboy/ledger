# Feature parity checklist

Generated by `tools/gen_parity.py` from `docs/data/original_inventory.json` (a dump of the original HTML game: 23 countries, 67 trades, 133 events, 105 screens, 557 actions, 43 company tabs, 179 extension pipelines).

An item is only marked beyond *Not ported* when code for it exists **and** the status describes what was actually checked.

| Status | Meaning |
|---|---|
| Verified | compared with the original game on identical inputs by an automated test, results equal |
| Statistical | compared with the original on average results over many seeds (random parts cannot match exactly) |
| Ported | ported; automated tests check it runs and keeps the books balanced; not compared number for number |
| Engine only | logic ported and tested, no native screen yet |
| Engine + screen | ported and reachable from a native screen. **The screens have not been run on a device or simulator by the author** (no Mac available); see KNOWN_GAPS |
| Not ported | not in the native game yet |
