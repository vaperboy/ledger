# Master audit: business systems (Stages 4, 6, 7, 8, 9)

Auditor: Claude (Sonnet 5.5), Stage 0, read-only on game code. Base: origin/native-swiftui (dd580ef). Spec read first (MASTER_SPEC sections 1-3, Stages 4, 6, 7, 8, 9; SIMULATION_RULES; DESIGN_RULES).
Method: code reading plus throwaway probe tests in a scratch Swift package outside the repo (Swift 6.0.3, Linux; engine only, the app was read, not run). Screenshots from `origin/ui-shots-iphone` (CI run of 28 Oct, so some screens may have changed since). Anything not run is marked INFERENCE. Old audits (CONN-xx) were re-checked: CONN-01, CONN-02 and CONN-13 are FIXED (see "already fine").

Probe facts used below (all run, engine only):
- P1 trade setup: 23 countries x up to 65 trades = 1,398 cells, `newCompanyPlan` + `startCompanyChoosingPremises(fundWith: plan.intoCompany)` exactly as the New company screen does it, then 42 days with payroll approvals answered. Scenario A = the default start cash; scenario B = player cash set to exactly the quoted total + registration/capital. Repeated for UK over 250 days.
- P2 shares: repeated primary issues, secondary sales and accepted pitch offers on a limited company.
- P3 startup: found a SaaS startup, play to launch and beyond; repeated funding rounds.
- P4 board: co-owner company, regular meetings, 30 weeks. P5 goals/trophies. P6 payroll alert after a lost case, then an award.

### Stage 4B: investment (four operations)

Existence: (1) new issuance exists (`Funding.pitch/acceptOffer`, `Funding.sellShares(mode primary)`, `Startups.pitchRound/acceptRound`, `raiseForHolding`); (2) existing-shareholder sale: **absent** (no operation lets an outside holder sell; a holder can only be bought out via `Shareholders.buyBack`); (3) founder stake sale exists as `sellShares(mode secondary)` and `listSharesForSale`; (4) full acquisition/exit exists for companies (`CompanySale`, `BigMeeting`) but not for founded startups. The UI shows no price per share and no share counts anywhere: the model holds percentages only.
