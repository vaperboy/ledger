# Picture brief: premises and luxury items
Same format as the faces: **one big image per sheet, a grid of equal cells, and a tag list in reading order** (left to right, top to bottom). Send the sheet and I slice it. No text, logos, watermarks or people in any picture. Use invented brands only, never real logos or plates. Same camera height, light and colour mood across a whole sheet so the game looks consistent (soft daylight, slightly muted colours, dark-friendly).
## Sheet 1: premises
- **Grid:** 4 columns x 11 rows = 44 cells. Each row is one kind of premises, each column is one size (S, M, L, XL).
- **Cell:** landscape 16:9, at least 640 x 360 px (whole sheet about 2560 x 3960 px). One picture per cell: the outside of the building from the street, with the inside in the same cell only if you want a split; keep it a single clear photo.
- **Columns, left to right:** S = Small, about 20 to 50 m2; M = Medium, about 50 to 150 m2; L = Large, about 150 to 500 m2; XL = Very large, 500 m2 and more

| Row | Kind (engine id) | What it is |
|---|---|---|
| 1 | `home` | Home / home office: a room or flat used as a workspace |
| 2 | `office` | Office: desks, meeting room, reception |
| 3 | `shop` | Shop / retail unit: shopfront with display window |
| 4 | `kitchen` | Kitchen / restaurant / café: dining room and open kitchen |
| 5 | `industrial` | Workshop / factory: machines, benches, light industrial |
| 6 | `warehouse` | Warehouse / depot: racking, loading bay |
| 7 | `hotel` | Hotel / guest house: exterior and lobby |
| 8 | `clinic` | Clinic / surgery: treatment rooms, waiting area |
| 9 | `yard` | Yard / site / open land: open yard, construction or farm yard |
| 10 | `gym` | Gym / studio: training floor, equipment |
| 11 | `slope` | Slope / outdoor venue: ski slope, mountain or outdoor venue base |

Tag list = row, then column: for example row 3 column 2 is `shop`, size M. A kind that does not exist in a big size (a home in XL) should be shown as a very large house.
